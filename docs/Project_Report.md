### 1. Project Overview
This project is a complete MERN stack application designed to manage employee records and integrate AI recommendations for HR decision-making. 
The system uses **Node.js/Express** for the backend, **MongoDB** for database storage, and **React + Vite** for a modern, responsive frontend styled with premium Vanilla CSS.
**OpenRouter AI** is used to generate personalized recommendations based on employee performance.
